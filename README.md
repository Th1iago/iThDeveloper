# IsaDeveloper — Portfolio Web

Portfolio personal desarrollado como proyecto de un curso de desarrollo web front-end.

## Tecnologías utilizadas

- HTML5
- SCSS (Sass) — arquitectura modular con partials, variables, mixins y @use
- CSS Grid y Flexbox
- Bootstrap 5 — Navbar responsivo y Carousel
- AOS (Animate On Scroll)

## Cómo compilar el SCSS

npm install -g sass
sass scss/main.scss styles/style.css
